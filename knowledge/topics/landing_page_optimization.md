# Landing Page Optimization

> Redirecting all site buttons to a dedicated landing page (not the homepage) can improve overall site conversion of existing traffic.

## Claims
- Moving from homepage to a dedicated landing page optimized for ads can eliminate the loss of ~50% traffic that occurs when adding intermediate steps. — [building_a_2_500_000_business_for_a_stranger_in_36_minutes_OQf2Ba-Lp_4.txt]
- Key landing page elements for conversion: free 18-point inspection headline (not generic verbiage like 'free assessment'), prominent phone number, form, locations, and FAQs; eliminate navigation and unnecessary elements. — [building_a_2_500_000_business_for_a_stranger_in_36_minutes_OQf2Ba-Lp_4.txt]
